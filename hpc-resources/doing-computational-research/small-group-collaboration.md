# Small group collaboration

**Goals:**

* coordinate subgroups in the group
* shared data, documentation, and research within the group
* encourage version control

1\) sign up for a [github account](https://github.com/signup)

2\) update the group roster with your github username

3\) join the group github, wangmatgroup (ask WW to send an invitation)

4\) recommendations for set up:

* structure data by raw data, plots and tables, scripts&#x20;
* use [jupyter notebooks](https://jupyter.org/)
* one repository per project
* one branch per person
* make changes locally first with git and then push to repo
* make a nice [README](https://www.makeareadme.com/)

5\) other relevant tools

* note taking tools for tracking research: [joplin](https://joplinapp.org/), [obsidian](https://obsidian.md/)
* create documentation from your python code: [sphinx](https://www.sphinx-doc.org/en/master/), [Mkdocs](https://www.mkdocs.org/)
